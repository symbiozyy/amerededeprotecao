# AME Redes de Proteção

Site de vendas e arquivos da identidade visual.

**Você cuida. A gente protege.**

## Site

Página única, sem dependências: `index.html` + `assets/`. Abra no navegador ou publique em qualquer hospedagem estática (GitHub Pages, Netlify, Vercel).

Para os botões de orçamento abrirem o WhatsApp, edite no fim do `index.html`:

```js
const WHATSAPP = "5511999999999"; // DDI + DDD + número, só dígitos
```

Enquanto estiver vazio, os botões abrem o Direct do Instagram.

## Marca (`assets/brand/`)

| Arquivo | Uso |
|---|---|
| `logo-horizontal.svg` | Principal, sobre fundo escuro |
| `logo-horizontal-claro.svg` | Sobre fundo claro |
| `logo-horizontal-preto.svg` / `-branco.svg` | Monocromático (âmbar, fotos, gravação) |
| `logo-vertical.svg` / `-claro.svg` | Versão empilhada |
| `simbolo*.svg` | Símbolo isolado |
| `avatar-instagram.svg` | Foto de perfil 1080 × 1080 |
| `favicon.svg`, `apple-touch-icon.png`, `og-image.png` | Web e compartilhamento |

Todo texto dos logos já está convertido em curvas: dá para mandar direto para a gráfica.

**Cores:** Noite `#0E0E0C` · Âmbar `#FFB23F` · Areia `#F5F0E6` · Âmbar forte `#F29A1F` · Concreto `#5C5850`
**Tipografia:** Archivo (Google Fonts). Títulos em Extra Condensed Black, caixa alta; textos em Regular/Bold.

## Obras (`assets/obras/`)

Fotos recortadas das publicações do Instagram. Troque por fotos em alta resolução quando possível, mantendo os mesmos nomes.
